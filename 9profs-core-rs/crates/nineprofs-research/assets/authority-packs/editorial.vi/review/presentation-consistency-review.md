# Review Guidance — Presentation Consistency

## Goal
Evaluate presentation-level consistency affecting readability or interpretation using semantic review plus deterministic sensors.

## Look especially for
- `vi-presentation/numeric-inconsistency`
- `vi-presentation/unit-inconsistency`
- `vi-presentation/heading-hierarchy`
- `vi-presentation/numbering`
- `vi-presentation/cross-reference`

LLM review should not manually inspect every punctuation mark or repeated space when deterministic sensors can do so more reliably.
