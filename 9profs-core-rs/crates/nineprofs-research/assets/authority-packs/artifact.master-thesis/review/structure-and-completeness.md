# Review Guidance — Structure and Completeness

## Goal
Evaluate whether the thesis contains the semantic components necessary to function as a coherent master's-level research artifact.

Identify actual document structure via Document Map and map sections to semantic roles.

## Look especially for
- `thesis-structure/missing-role`
- `thesis-structure/disconnected-sections`
- `thesis-structure/imbalanced-development`
- `thesis-structure/redundant-architecture`

Do not judge imbalance by page count alone.
